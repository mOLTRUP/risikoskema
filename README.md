# Risikoskema

Version 0.2 af HACCP-risikoskemaerne for fødevarer og foder, med risiko-overskrifter (fx Ordremodtagelse), farvevurdering og liggende A4-udskrift.

## Online test

Testside: https://moltrup.github.io/risikoskema/ (når GitHub Pages er aktiveret).

Den aktuelle side ligger i `index.html` og `site/index.html`. Det er en statisk demo, ikke en produktionsudgave af WordPress.

Det komplette projekt med WordPress-plugin, Excel- og PDF-referencer er samlet i projektpakken fra ChatGPT. Følsomme eller udfyldte kundedata må ikke offentliggøres i GitHub.
